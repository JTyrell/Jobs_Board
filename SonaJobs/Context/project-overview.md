# SONJA Jobs Board

## Overview
A comprehensive job board platform with integrated CRM features built using Django and Bootstrap 5. The platform serves as a two-sided marketplace connecting Job Seekers with Employers, facilitating the entire recruitment lifecycle from job posting to application management and direct communication.

## Goals
1. Provide a seamless and intuitive job search experience for candidates.
2. Offer employers a robust dashboard to post jobs and manage applicant pipelines.
3. Streamline communication between parties with built-in CRM functionalities (messaging, notifications, alerts).

## Core User Flow
1. **Onboarding**: Users register and define their persona (Job Seeker or Employer) and fill out their respective profiles.
2. **Discovery**: Employers post jobs; Job Seekers browse, search, and set alerts for matching jobs.
3. **Engagement**: Job Seekers apply to jobs. Employers review applications and initiate communication via the platform.

## Features
### Job Seekers
- Profile creation with resume upload.
- Advanced job search and filtering.
- Save jobs and create job alerts (daily, weekly, instant).
- Application tracking dashboard.

### Employers
- Company profile management.
- Job posting creation and status management (draft, published, closed).
- Applicant tracking system (ATS) features.
- Direct messaging with applicants.

### CRM & System
- Internal messaging thread system.
- Automated email and platform notifications.
- Site analytics and event tracking.

## Success Criteria
1. Stable, fast, and responsive UI across devices.
2. Zero deployment downtime with CI/CD on Railway.
3. High user retention through relevant job alerts and matching algorithms.
